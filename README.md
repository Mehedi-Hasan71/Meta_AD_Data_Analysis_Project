# Meta AD Data Analysis Project

## 📌 Project Overview

This project presents a comprehensive Meta (Facebook & Instagram) advertising performance analysis dashboard developed using Power BI. The dashboard helps marketing teams monitor campaign performance, evaluate audience engagement, analyze conversion effectiveness, and make data-driven decisions to optimize advertising strategies.

## 🎯 Business Objective

The primary objective of this project is to:

* Monitor advertising performance across Meta platforms.
* Analyze audience behavior and engagement.
* Identify high-performing demographics and ad formats.
* Measure campaign effectiveness through key performance indicators (KPIs).
* Provide actionable insights to improve Return on Investment (ROI).

## 🛠️ Tools & Technologies

* Power BI
* DAX (Data Analysis Expressions)
* Power Query
* Microsoft Excel
* Data Visualization
* Data Cleaning & Transformation

## 📊 Key Performance Indicators (KPIs)

The dashboard tracks the following metrics:

* Impressions
* Clicks
* Shares
* Comments
* Purchases
* Engagements
* Click-Through Rate (CTR)
* Engagement Rate
* Conversion Rate
* Purchase Rate
* Total Campaign Budget
* Average Campaign Budget

## 📈 Dashboard Features

### Executive KPI Overview

Provides a high-level summary of campaign performance through dynamic KPI cards.

### Audience Analysis

* Clicks by Gender
* Clicks by Age Group

### Geographic Analysis

* Campaign performance by country
* Regional audience engagement insights

### Trend Analysis

* Weekly Engagement Trend
* Hourly Engagement Trend

### Ad Performance Analysis

Comparison of different ad formats:

* Video Ads
* Image Ads
* Stories Ads
* Carousel Ads

### Interactive Filters

Users can dynamically filter data by:

* Platform (Facebook / Instagram)
* Campaign Name
* Target Interest
* Performance Metrics

## 🔍 Key Insights

* Female audiences generated higher engagement compared to other audience segments.
* Users aged between 20 and 35 years showed the strongest interaction with advertisements.
* Video advertisements delivered the highest engagement and conversion performance.
* Certain geographic regions consistently outperformed others in campaign effectiveness.
* Engagement activity peaked during specific hours, indicating optimal ad scheduling opportunities.

## 💡 Recommendations

* Increase budget allocation toward high-performing audience segments.
* Prioritize video-based advertising campaigns.
* Optimize ad delivery schedules based on peak engagement hours.
* Focus marketing efforts on high-converting geographic regions.
* Continuously monitor CTR, Engagement Rate, and Conversion Rate to improve ROI.
